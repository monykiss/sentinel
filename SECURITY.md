# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through
**[GitHub private vulnerability reporting](../../security/advisories/new)** on this
repository.

Include a description, steps to reproduce, and the impact you expect. You will
get an acknowledgement within 72 hours.

## Scope

This repository contains the client-side surface of SENTINEL: the Python SDK,
the MCP server and the CLI. Reports about how these clients handle credentials,
errors or untrusted input are in scope.

Good-faith research that avoids privacy violations and data destruction, and
allows reasonable time for a fix before disclosure, will not be pursued legally.
